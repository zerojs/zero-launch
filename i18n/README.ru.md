## ✨ ZeroLaunch Highlights

ZeroLaunch активно развивается на базе LaunchNext. Вот что **добавляет этот форк** сверх оригинала:

- ⚡ **Переработка производительности на уровне движка** — обновление дерева слоёв по различиям: перерисовываются только изменившиеся иконки вместо пересборки 500+ слоёв; прокрутка страниц ощущается одинаково на экранах 60 и 120 Гц; кэш иконок с учётом масштаба и ограниченным объёмом; инкрементальное сохранение (одно перетаскивание — одна запись на диск)
- 🗑️ **Режим удаления по долгому нажатию** — режим «дрожания» в стиле iOS с безопасным перемещением в Корзину и многоуровневым понижением прав (даже приложения App Store, принадлежащие root, можно отправить в Корзину)
- 📁 **Открытие папок при наведении** — удерживайте приложение над папкой, и она автоматически раскроется через момент; отпустите внутри, чтобы разместить приложение точно где нужно
- 🧲 **Перелистывание у края экрана с подсказкой** — перетащите приложение к краю экрана, чтобы листнуть страницу с видимой полоской-подсказкой; пустые страницы переиспользуются, поэтому беспорядок не накапливается
- 🎬 **Симметричные анимации открытия и закрытия** — при открытии панель сжимается к центру, при закрытии — расширяется наружу; длительность настраивается
- 🗂️ **Раскрытие папок в стиле LaunchOS** — папка вырастает из иконки, по которой вы нажали; переименование одним кликом с адаптивным полем ввода
- ⚙️ **Полностью переработанные настройки** — поиск внутри настроек с навигацией с клавиатуры, сброс по разделам, переключатель области применения «полный экран / окно» и группировка связанных параметров в карточки
- 🧹 **Проверенные и очищенные параметры** — удалены мёртвые настройки, унифицированы названия «Fullscreen / Window», числовой ползунок веса шрифта, живой отсчёт использования памяти и быстрый перезапуск после смены режима производительности
- 🌍 **14 языков** — каждая новая настройка сразу локализована (en, zh-Hans, zh-Hant, ja, ko, fr, es, de, ru, it, cs, pt-BR, vi, hi)
- 🚢 **Независимая дистрибуция** — собственный Bundle ID, команда `zerolaunch`, встроенный автообновлятель и скрипты сборки релиза
- 🛠️ **Реальные исправления ошибок** — фон обоёв macOS 26 (подбор локального окна + резервный вариант на уровне файла), случайная потеря фокуса окном настроек, слишком маленькие области нажатия у опасных кнопок и др.

## 🚀 Установка

### Вариант 1 — Скачать готовый релиз
1. Скачайте `ZeroLaunch<версия>.zip` из [последнего релиза](https://github.com/zerojs/zero-launch/releases/latest)
2. Распакуйте и перетащите `ZeroLaunch.app` в `/Applications`
3. Запустите — если macOS заблокирует приложение, см. примечание ниже

### Вариант 2 — Сборка из исходников

См. [Сборка из исходного кода](#сборка-из-исходного-кода) ниже.

> ⚠️ **Если macOS блокирует приложение, выполните это в Терминале:**
```bash
sudo xattr -r -d com.apple.quarantine /Applications/ZeroLaunch.app
```
**Почему**: релизы ZeroLaunch сейчас подписаны adhoc и не нотаризованы (нет платного аккаунта Apple Developer), поэтому macOS по умолчанию блокирует неподписанные приложения. Эта команда снимает флаг карантина, чтобы разрешить запуск. **Используйте эту команду только с приложениями, которым доверяете.** Можно также нажать правой кнопкой по приложению → **Открыть** → подтвердить.

**Статус подписи**: сейчас релизы **подписаны adhoc, но не нотаризованы**. При первом запуске Gatekeeper может предупредить; см. команду выше или нажмите правой кнопкой → Открыть. Когда позже появится платный аккаунт Apple Developer, релизы перейдут на подпись Developer ID и нотаризацию. Собираете из исходников? См. [Настройка локальной подписи](#configure-local-code-signing).

## Сборка из исходного кода

### Требования
- macOS 26 (Tahoe) или новее
- Процессор Apple Silicon или Intel
- Xcode 26 (для сборки из исходников)

### Сборка из исходного кода

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/zerojs/zero-launch.git
   cd zero-launch
   ```

2. **Откройте в Xcode**
   ```bash
   open LaunchNext.xcodeproj
   ```

3. <a name="configure-local-code-signing"></a>**Настройте локальную подпись кода**
   - Платный аккаунт Apple Developer не требуется для сборки или участия в разработке ZeroLaunch.
   - Выберите target **LaunchNext**, откройте **Signing & Capabilities**, задайте **Team** — свою команду (бесплатная Personal Team подойдёт) либо установите **Team** в `None` и выберите сертификат `Sign to Run Locally`.
   - Оставьте Hardened Runtime включённым.
   - Xcode может пометить файл проекта как изменённый после правки локальных настроек. Не включайте изменения, связанные только с подписью, в pull request.

4. **Соберите и запустите**
   - Чтобы запустить приложение через `⌘+R`, выберите `My Mac` в качестве устройства запуска, а не `Any Mac`.
   - `Any Mac (arm64, x86_64)` предназначен для общих сборок и архивов; на нём нельзя запустить приложение для отладки.
   - Нажмите `⌘+B`, если нужно только собрать проект.

### Сборка из командной строки

**Обычная сборка:**
```bash
xcodebuild -project LaunchNext.xcodeproj -scheme LaunchNext -configuration Release
```

**Универсальный бинарник (Intel + Apple Silicon):**
```bash
xcodebuild -project LaunchNext.xcodeproj -scheme LaunchNext -configuration Release ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO clean build
```

**Релизный пакет (zip + контрольные суммы, adhoc-подпись):**
```bash
./scripts/release.sh
```

## Использование

### Начало работы
1. **Первый запуск**: ZeroLaunch автоматически сканирует все установленные приложения
2. **Выбор**: нажмите, чтобы выбрать приложение, двойной щелчок — чтобы запустить
3. **Поиск**: начните вводить — приложения фильтруются мгновенно
4. **Организация**: перетаскивайте приложения, чтобы создавать папки и свои компоновки
5. **Автоматизация**: включите CLI в Настройках, если нужны рабочие процессы из терминала

### Импорт вашего Launchpad
1. Откройте Настройки (значок шестерёнки)
2. Нажмите **«Import Launchpad»**
3. Ваша существующая компоновка и папки импортируются автоматически


### Режимы отображения
- **Окно**: плавающее окно со скруглёнными углами
- **Полный экран**: режим на весь экран для максимальной обзорности
- **Legacy Engine** и **Next Engine + Core Animation** доступны в Настройках
- ZeroLaunch может хранить отдельные настройки для полноэкранного и оконного режимов
- Доступно скрытие меню-бара в полноэкранном режиме; при этом macOS также скрывает Dock

## Устранение неполадок

### Общие проблемы

**Q: Приложение не запускается?**  
A: Убедитесь, что у вас macOS 26.0+ и проверьте разрешения системы. Если приложение заблокировано Gatekeeper, выполните `sudo xattr -r -d com.apple.quarantine /Applications/ZeroLaunch.app` или нажмите правой кнопкой → Открыть.

**Q: Какой движок использовать?**  
A: `Next Engine + Core Animation` рекомендуется для лучшего опыта. `Legacy Engine` остаётся доступным, если нужен старый путь совместимости.

**Q: Почему команда CLI ещё не появилась?**  
A: Сначала включите интерфейс командной строки в Настройках. ZeroLaunch может установить и удалить управляемую команду `zerolaunch`.
