## ✨ ZeroLaunch हाइलाइट्स

ZeroLaunch, LaunchNext के आधार पर सक्रिय रूप से विकसित हो रहा है। मूल प्रोजेक्ट की तुलना में **इस fork में** क्या जोड़ा गया है:

- ⚡ **इंजन-स्तरीय प्रदर्शन सुधार** — layer-tree diffing केवल बदलने वाले आइकन को दोबारा रेंडर करता है, 500+ लेयर को फिर से बनाने के बजाय; पेज स्क्रॉल 60Hz और 120Hz स्क्रीन पर बिलकुल एक जैसा महसूस होता है; स्केल-अवेयर आइकन कैशिंग (सीमित आकार के cache के साथ); इन्क्रीमेंटल सेव (एक ड्रैग = एक बार डिस्क पर लिखना)
- 🗑️ **लॉन्ग-प्रेस अनइंस्टॉल मोड** — iOS-शैली का jiggle मोड, सुरक्षित ट्रैश फ़्लो और कई स्तरों की अनुमति fallback (यहाँ तक कि root-स्वामित्व वाले App Store ऐप भी ट्रैश किए जा सकते हैं)
- 📁 **होवर करते ही खुलने वाले फ़ोल्डर** — किसी ऐप को फ़ोल्डर पर थोड़ी देर रखें, वह अपने आप खुल जाता है; अंदर छोड़ दें तो ऐप बिलकुल उसी जगह रख दिया जाता है
- 🧲 **किनारे से पेज पलटना + एज हिंट** — ऐप को स्क्रीन के किनारे ले जाकर पेज पलटें, साथ ही एक दृश्य हिंट बार दिखता है; खाली पेज दोबारा इस्तेमाल होते रहते हैं, इसलिए अव्यवस्था नहीं बढ़ती
- 🎬 **सममित खोलने/बंद करने के एनिमेशन** — खोलते समय पैनल केंद्र की ओर सिकुड़ता है और बंद करते समय बाहर की ओर फैलता है; अवधि कॉन्फ़िगर करने योग्य है
- 🗂️ **LaunchOS-शैली का फ़ोल्डर विस्तार** — फ़ोल्डर उसी आइकन से बाहर की ओर खुलता है जिसे आपने क्लिक किया; अनुकूली इनपुट बॉक्स से एक क्लिक में नाम बदलें
- ⚙️ **पूरी तरह से नया बना Settings** — Settings के अंदर खोज और कीबोर्ड नेविगेशन, हर सेक्शन के लिए रीसेट, Fullscreen/Window स्कोप स्विचर, और संबंधित विकल्पों का कार्ड में समूहीकरण
- 🧹 **ऑडिट और सफ़ाई किए गए विकल्प** — बेकार settings हटाए गए, Fullscreen/Window नामकरण एक जैसा किया गया, फ़ॉन्ट-वेट के लिए संख्यात्मक स्लाइडर, लाइव मेमोरी उपयोग दिखावट, और प्रदर्शन मोड बदलने के तुरंत बाद रीस्टार्ट का शॉर्टकट
- 🌍 **14 भाषाएँ** — हर नई setting के साथ लोकलाइज़ेशन आता है (en, zh-Hans, zh-Hant, ja, ko, fr, es, de, ru, it, cs, pt-BR, vi, hi)
- 🚢 **स्वतंत्र वितरण** — अपना खुद का bundle ID, `zerolaunch` CLI, अंदरूनी self-updater, और release स्क्रिप्ट
- 🛠️ **असली bug फ़िक्स** — macOS 26 वॉलपेपर बैकग्राउंड (स्थानीयकृत विंडो मैचिंग + फ़ाइल-स्तरीय fallback), settings शीट का फ़ोकस खोना, खतरनाक बटनों के छोटे हिट-एरिया, और भी बहुत कुछ

## 🚀 इंस्टॉलेशन

### विकल्प 1 — रिलीज़ डाउनलोड करें

1. [सबसे नई रिलीज़](https://github.com/zerojs/zero-launch/releases/latest) से `ZeroLaunch<संस्करण>.zip` प्राप्त करें
2. इसे अनज़िप करें और `ZeroLaunch.app` को `/Applications` में खींचें
3. इसे चलाएँ — अगर macOS इसे ब्लॉक करे, नीचे दिया गया नोट देखें

### विकल्प 2 — सोर्स से बिल्ड करें

नीचे [सोर्स से बिल्ड करें](#build-from-source) देखें।

> ⚠️ **यदि macOS एप्लिकेशन को ब्लॉक कर दे, तो टर्मिनल में यह चलाएँ:**
```bash
sudo xattr -r -d com.apple.quarantine /Applications/ZeroLaunch.app
```
**क्यों**: ZeroLaunch रिलीज़ वर्तमान में ad-hoc साइन की गई हैं और अभी तक notarized नहीं हैं (पेड Apple Developer सदस्यता नहीं है), इसलिए macOS डिफ़ॉल्ट रूप से बिना साइन वाले ऐप को ब्लॉक करता है। यह कमांड quarantine फ्लैग हटाकर इसे चलने देती है। **केवल विश्वसनीय ऐप पर ही इस कमांड का उपयोग करें।** आप ऐप पर राइट-क्लिक → **Open** → पुष्टि भी कर सकते हैं।

**कोड साइनिंग स्थिति**: रिलीज़ वर्तमान में **ad-hoc साइन की गई हैं, notarized नहीं**। पहली बार चलाने पर Gatekeeper चेतावनी दे सकता है; ऊपर दी गई कमांड इस्तेमाल करें या राइट-क्लिक → Open करें। भविष्य में पेड Apple Developer सदस्यता जोड़ने पर रिलीज़ Developer ID साइनिंग + notarization पर चली जाएँगी। सोर्स से बिल्ड कर रहे हैं? [स्थानीय कोड साइनिंग कॉन्फ़िगर करें](#configure-local-code-signing) देखें।

### ZeroLaunch क्या देता है

- ✅ **पुराने सिस्टम Launchpad से वन-क्लिक आयात** - नेटिव Launchpad SQLite डेटाबेस (`/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db`) को सीधे पढ़कर मौजूदा फ़ोल्डर, ऐप की स्थितियाँ और लेआउट बिलकुल दोबारा बनाता है
- ✅ **क्लासिक Launchpad अनुभव** - बिलकुल उसी तरह काम करता है जैसे पसंदीदा मूल इंटरफ़ेस
- ✅ **बहुभाषी समर्थन** - English, Simplified Chinese, Traditional Chinese, Japanese, French, Spanish, German, Russian और भी कई भाषाओं में पूरा internationalization
- ✅ **आइकन लेबल छिपाएँ** - जब ऐप के नाम चाहिए न हों, एक साफ़, न्यूनतम दृश्य
- ✅ **कस्टम आइकन आकार** - अपनी पसंद के अनुसार आइकन का आकार बदलें
- ✅ **स्मार्ट फ़ोल्डर प्रबंधन** - पहले की तरह ही फ़ोल्डर बनाएँ और व्यवस्थित करें
- ✅ **फ़ज़ी खोज और कीबोर्ड नेविगेशन** - आंशिक या गलत इनपुट के साथ भी ऐप जल्दी ढूँढें
- ✅ **CLI / TUI समर्थन** - `zerolaunch` कमांड से टर्मिनल में अपना लेआउट देखें और चलाएँ
- ✅ **Hot Corner और नेटिव जेस्चर समर्थन** - कोनों, ट्रैकपैड जेस्चर और 4 / 5-उंगली विकल्पों से ZeroLaunch खोलें
- ✅ **ऐप्स को सीधे Dock में खींचें** - Next Engine + Core Animation में उपलब्ध
- ✅ **Core Animation फ़ोल्डर** - फ़ोल्डर सामग्री पेज और वर्टिकल स्क्रॉल लेआउट को सपोर्ट करती है
- ✅ **बेहतर कॉन्टेक्स्ट मेन्यू** - Show in Finder, Copy App Path, Rename Folder, और कॉन्फ़िगर किया गया uninstall ऐक्शन
- ✅ **Markdown रिलीज़ नोट्स वाला अपडेट टैब** - अधिक समृद्ध इन-ऐप अपडेट अनुभव
- ✅ **बैकअप, कंट्रोलर और वॉइस समर्थन में सुधार** - बेहतर विश्वसनीयता और एक्सेसिबिलिटी

## सोर्स से बिल्ड करें

### आवश्यकताएँ

- macOS 26 (Tahoe) या बाद का संस्करण
- Apple Silicon या Intel प्रोसेसर
- Xcode 26 (सोर्स से बिल्ड करने के लिए)

<a name="build-from-source"></a>
### सोर्स से बिल्ड करें

1. **रिपॉजिटरी क्लोन करें**
   ```bash
   git clone https://github.com/zerojs/zero-launch.git
   cd zero-launch
   ```

2. **Xcode में खोलें**
   ```bash
   open LaunchNext.xcodeproj
   ```

3. <a name="configure-local-code-signing"></a>**स्थानीय कोड साइनिंग कॉन्फ़िगर करें**
   - ZeroLaunch बिल्ड करने या इसमें योगदान देने के लिए पेड Apple Developer सदस्यता ज़रूरी नहीं है।
   - **LaunchNext target** चुनें, **Signing & Capabilities** खोलें, **Team** को अपनी टीम पर सेट करें (फ्री Personal Team भी काम करेगा), या **Team** को `None` करके साइनिंग सर्टिफिकेट के रूप में `Sign to Run Locally` चुनें।
   - Hardened Runtime सक्षम रखें।
   - इन स्थानीय सेटिंग्स बदलने के बाद Xcode प्रोजेक्ट फ़ाइल को modified मार्क कर सकता है। Pull request में सिर्फ साइनिंग से जुड़े बदलाव शामिल न करें।

4. **बिल्ड और रन करें**
   - `⌘+R` से ऐप चलाने के लिए रन डेस्टिनेशन `My Mac` चुनें — `Any Mac` नहीं।
   - `Any Mac (arm64, x86_64)` सामान्य बिल्ड और आर्काइव के लिए है; इससे डिबगिंग के लिए ऐप लॉन्च नहीं हो सकता।
   - अगर सिर्फ बिल्ड चाहिए तो `⌘+B` दबाएँ।

### कमांड लाइन बिल्ड

**सामान्य बिल्ड:**
```bash
xcodebuild -project LaunchNext.xcodeproj -scheme LaunchNext -configuration Release
```

**यूनिवर्सल बाइनरी बिल्ड (Intel + Apple Silicon):**
```bash
xcodebuild -project LaunchNext.xcodeproj -scheme LaunchNext -configuration Release ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO clean build
```

**रिलीज़ पैकेज (zip + चेकसम, ad-hoc साइन):**
```bash
./scripts/release.sh
```

## उपयोग

### शुरुआत करना

1. **पहला लॉन्च**: ZeroLaunch अपने आप सभी इंस्टॉल किए गए ऐप स्कैन करता है
2. **चयन**: चुनने के लिए क्लिक करें, खोलने के लिए डबल-क्लिक
3. **खोज**: टाइप करते ही ऐप फ़िल्टर हो जाते हैं
4. **व्यवस्थित करना**: फ़ोल्डर और कस्टम लेआउट बनाने के लिए ऐप खींचें
5. **ऑटोमेशन**: अगर टर्मिनल वर्कफ़्लो चाहिए तो Settings में CLI सक्षम करें

### अपना Launchpad आयात करें

1. सेटिंग्स खोलें
2. **Import Launchpad** पर क्लिक करें
3. आपका मौजूदा लेआउट और फ़ोल्डर स्वचालित रूप से आयात हो जाएंगे

### डिस्प्ले मोड

- **Window**: गोल कोनों वाली फ़्लोटिंग विंडो
- **Fullscreen**: अधिकतम दृश्यता के लिए फुल-स्क्रीन मोड
- **Legacy Engine** और **Next Engine + Core Animation** Settings में उपलब्ध हैं
- ZeroLaunch फुलस्क्रीन और window मोड के लिए अलग-अलग सेटिंग्स रख सकता है
- वैकल्पिक फुलस्क्रीन मेन्यू बार छिपाना उपलब्ध है; इसमें macOS डॉक भी छिपा देता है

## उन्नत फ़ीचर

### खोज और फ़ोल्डर अनुभव

- **फ़ज़ी खोज**: आंशिक नाम, संक्षिप्त रूप और गलत इनपुट से ऐप मैच करें
- **कॉन्फ़िगर करने योग्य खोज देरी**: Settings में search debounce टाइमिंग ट्यून करें
- **फ़ोल्डर लेआउट मोड**: Launchpad-जैसे पेज वाले फ़ोल्डर और वर्टिकल स्क्रॉल फ़ोल्डर में से चुनें
- **Core Animation फ़ोल्डर रेंडरिंग**: बड़े फ़ोल्डर के लिए स्मूथ इंटरैक्शन

### स्मार्ट बैकग्राउंड इंटरैक्शन

- बुद्धिमान क्लिक डिटेक्शन से गलती से बंद होने से बचाव
- संदर्भ-आधारित जेस्चर हैंडलिंग
- सर्च फ़ील्ड सुरक्षा

### प्रदर्शन अनुकूलन

- **आइकन कैशिंग**: स्मूथ स्क्रॉलिंग के लिए बुद्धिमान इमेज कैशिंग
- **लेज़ी लोडिंग**: कुशल मेमोरी उपयोग
- **बैकग्राउंड स्कैनिंग**: बिना रुकावट ऐप खोज

### ऑटोमेशन और सक्रियण

- **CLI / TUI**: `zerolaunch` से टर्मिनल में ZeroLaunch चलाएँ
- **Hot Corner**: कॉन्फ़िगर स्क्रीन कोने से ZeroLaunch खोलें
- **प्रायोगिक नेटिव जेस्चर**: 4 / 5-उंगली pinch और tap क्रियाएँ, बाहरी ट्रैकपैड डिवाइस चुनने सहित
- **Dock ड्रैग**: Next Engine + Core Animation में ऐप को सीधे macOS Dock में खींचें

## समस्या निवारण

### सामान्य समस्याएँ

**Q: ऐप शुरू नहीं हो रहा?**  
A: macOS 26.0+ होना सुनिश्चित करें और सिस्टम अनुमतियाँ जाँचें। अगर Gatekeeper ऐप ब्लॉक करे, `sudo xattr -r -d com.apple.quarantine /Applications/ZeroLaunch.app` चलाएँ या राइट-क्लिक → Open करें।

**Q: कौन सा इंजन उपयोग करना चाहिए?**  
A: सर्वोत्तम अनुभव के लिए `Next Engine + Core Animation` अनुशंसित है। अगर पुराना compatibility path चाहिए तो `Legacy Engine` अभी भी उपलब्ध है।

**Q: CLI कमांड अभी तक क्यों नहीं है?**  
A: पहले Settings में command line interface सक्षम करें। ZeroLaunch आपके लिए प्रबंधित `zerolaunch` कमांड इंस्टॉल और हटा सकता है।
